# 🚀 Инструкция по запуску проекта

## ⚠️ ВАЖНО: Проблема с PowerShell

В вашем PowerShell обнаружена проблема — все команды выполняются с префиксом `qс`, что делает невозможным выполнение команд напрямую.

**Пример:** Вместо `docker ps` выполняется `qсdocker ps` ❌

### Решение
Используйте `.bat` скрипты, которые работают через CMD и обходят проблему PowerShell.

---

## 📝 Пошаговая инструкция

### Шаг 1: Убедитесь, что Docker Desktop запущен

1. Откройте Docker Desktop
2. Дождитесь, пока иконка в трее перестанет мигать
3. Убедитесь, что Docker работает

---

### Шаг 2: Примените миграции базы данных

**Дважды кликните на файл:**
```
docker-migrate.bat
```

**Что делает скрипт:**
- Проверяет, запущен ли контейнер базы данных
- Запускает контейнер, если он остановлен
- Применяет все Prisma миграции (включая новую для категорий)

**Ожидаемый результат:**
```
[SUCCESS] Migrations applied successfully!
```

---

### Шаг 3: Запустите приложение

**Дважды кликните на файл:**
```
docker-start.bat
```

**Что делает скрипт:**
- Запускает базу данных (если не запущена)
- Собирает Docker образ приложения
- Запускает контейнер с API

**Ожидаемый результат:**
```
[SUCCESS] Application started successfully!

Services:
- Database: localhost:5433
- API: http://localhost:3001
- Swagger: http://localhost:3001/api-docs
- WebSocket Test: http://localhost:3001/websocket-test
```

---

### Шаг 4: Проверьте работу

Откройте в браузере:

1. **API Health Check:**
   ```
   http://localhost:3001/health
   ```
   Ожидается: `{"status":"ok"}`

2. **Swagger документация:**
   ```
   http://localhost:3001/api-docs
   ```

3. **Тест WebSocket:**
   ```
   http://localhost:3001/websocket-test
   ```

## 🔍 Устранение проблем

### Проблема: "Database container is not running"
**Решение:**
1. Откройте Docker Desktop
2. Убедитесь, что Docker запущен
3. Запустите `docker-start.bat`

### Проблема: "Port 3001 is already in use"
**Решение:**
1. Откройте Task Manager (Диспетчер задач)
2. Найдите процесс, использующий порт 3001
3. Завершите процесс
4. Или измените порт в `.env`: `PORT=3002`

### Проблема: "Migration failed"
**Решение:**
1. Убедитесь, что база данных запущена: `docker-start.bat`
2. Подождите 10-15 секунд
3. Повторите `docker-migrate.bat`

### Проблема: Префикс "qс" всё ещё появляется
**Решение:**
- НЕ используйте PowerShell напрямую
- Используйте только `.bat` файлы
- Или откройте обычный CMD (не PowerShell)

## 🆘 Всё ещё не работает?

1. **Перезапустите Docker Desktop**
2. **Удалите все контейнеры и начните заново:**
   - Дважды кликните `docker-stop.bat`
   - Откройте Docker Desktop
   - Удалите все контейнеры с именем `backend-todo`
   - Запустите `docker-start.bat`

3. **Проверьте логи:**
   - Дважды кликните `docker-logs.bat`
   - Найдите ошибки (строки с `ERROR` или `FATAL`)
