# Применение миграций - ИНСТРУКЦИЯ

## ⚠️ Важно: Используйте CMD, а не PowerShell!

Из-за проблем с PowerShell используйте **обычную командную строку Windows (CMD)**.

## Быстрый способ

1. Откройте **командную строку CMD** (Win+R → введите `cmd` → Enter)
2. Перейдите в папку проекта:
   ```
   cd C:\work\apps\backend-todo
   ```
3. Запустите батник:
   ```
   apply-migrations.bat
   ```

Или просто **двойной клик** на файл `apply-migrations.bat` в проводнике Windows.

## Альтернатива: Напрямую через npx

В CMD выполните:
```
npx prisma db push
```

## Что делает скрипт

1. Проверяет подключение к базе данных
2. Добавляет поля `priority` и `task_time` в таблицу `tasks`
3. Генерирует Prisma Client

После выполнения перезапустите сервер: `npm run dev`
